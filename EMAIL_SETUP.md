# Configuração de Email Gratuito para RDVEX

## Opção 1: DuckDNS + Mailgun (Gratuito)

### Passo 1: Criar domínio DuckDNS
1. Acesse https://www.duckdns.org
2. Faça login com Google/Twitter
3. Crie subdomínio: `rdvex` 
4. Domínio será: rdvex.duckdns.org

### Passo 2: Configurar Mailgun gratuito
1. Acesse https://www.mailgun.com
2. Crie conta gratuita (5.000 emails/mês)
3. Adicione domínio rdvex.duckdns.org
4. Configure DNS TXT records no DuckDNS
5. Verificar domínio

### Passo 3: Criar email
Email será: contato@rdvex.duckdns.org

## Opção 2: Zoho Mail Gratuito
1. Zoho oferece 5 contas grátis com domínio próprio
2. Precisa de domínio próprio (Namecheap: $10/ano)
3. Email: contato@rdvex.tech

## Opção 3: Simplificado - Use Gmail
Crie email: rdvex.contato@gmail.com
Ou use formulário que direciona para WhatsApp

## Recomendação
Para site institucional, o melhor é registrar domínio próprio:
- Namecheap: rdvex.tech por $10/ano
- Com isso usa Zoho Mail grátis
